# 校园美食推荐与评价系统

基于微信小程序的校园美食推荐与评价系统，为学生提供便捷的校园餐厅信息查询、菜品推荐和评价功能。

## 📱 功能特性

- 用户认证: 微信一键登录 + 学号认证
- 餐厅浏览: 查看校园内所有餐厅信息
- 智能推荐: 基于用户偏好和历史行为的个性化推荐
- 菜品评价: 对菜品进行评分和评论
- 收藏功能: 收藏喜欢的餐厅和菜品
- 搜索功能: 按餐厅名称、菜品类别搜索

## 🛠️ 技术栈

### 前端
- 框架: uni-app (Vue 3)
- UI库: uView UI
- 平台: 微信小程序

### 后端
- 框架: Spring Boot 2.7.x
- 数据库: MySQL 8.0
- ORM: MyBatis-Plus
- 安全: Spring Security + JWT

### 开发工具
- IDE: HBuilderX (前端), IntelliJ IDEA (后端)
- 版本控制: Git + GitHub
- API测试: Postman
